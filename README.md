WHAT THIS IS
------------
This game is a from-source reconstruction of the unlicensed Mega Drive
port of Super Mario World ("Super Mario World (Taiwan) (En) (Unl)"),
retargeted to run on NEC's PC-FX home console. 

Gameplay covers the full 19-level progression with seven boss battles,
crates, gems, fireballs, heart damage, a reserve-lives/continue system
and the original title and menu flow. 
Music is delivered as Red Book CD-DA audio tracks.

HOW TO RUN
----------
Load smb_pcfx.cue in a PC-FX emulator (for example pcfxemu or Mednafen)
or burn the bin/cue set to a CD-R. Keep all .bin files next to the .cue:
the data track is smb_pcfx.bin and the audio tracks are the
smb_pcfx_*.bin files. The game starts from the CD like the retail discs.

CONTROLS
--------
  D-pad  - move Mario
  I      - jump
  II     - lift/throw crate
  III    - throw fireball
  RUN    - Pause / start game

BETA STATUS

Please report issues if you do encounter them.
